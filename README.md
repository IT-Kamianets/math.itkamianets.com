# MathLearn

Базовий каркас платформи для вивчення математики у 5–9 класах.

## Запуск

```bash
npm install
npm run dev
```

Для production-збірки виконайте `npm run build`, для локального перегляду зібраної версії — `npm run preview`.

## Стек

- React 18 + TypeScript
- Vite
- React Router v6
- Tailwind CSS

У застосунку є сторінки «Головна», «Практика», «Теорія», «Профіль» та 404. Вони поки що містять лише заглушки; бізнес-логіки немає.
